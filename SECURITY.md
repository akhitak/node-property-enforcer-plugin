# Security

Do not disclose a suspected vulnerability in a public issue or pull request. Follow the [Jenkins security reporting process](https://www.jenkins.io/security/reporting/) to report it privately.

Include the plugin version, Jenkins and Java versions, optional provider versions, reproduction steps and expected impact. Use minimal test data and remove credentials and private organization details.

The development snapshot is not an approved Jenkins community release. Validation evidence describes the tested versions and workloads; it does not guarantee the absence of vulnerabilities or resource issues in every environment.
