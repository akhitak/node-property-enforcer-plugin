Add the checkboxes users must turn on under Node Properties in each node's configuration. Only rows with “Require this option” checked apply. With no required options, this plugin does not restrict saving nodes or running builds.

Unavailable options are marked in the list. Selecting one while “Require this option” is checked shows its setup instructions below that selection. Choose an available option or uncheck the requirement to clear the error. Empty rows are ignored when saving.

Existing nodes are included. To give users time to update them, leave warnings checked and uncheck both “Allow new builds only on nodes with all required options enabled” and “Check required options before saving existing nodes”. You can check those settings later.

Creating or copying a node through the web form always requires the selected options before saving. The built-in controller is excluded. This plugin does not disconnect nodes or stop builds already running.

Node-based security: at least one user or group must have a node permission selected. On new nodes, the signed-in creator is added with all permissions available for that node. This does not grant global permissions. Existing nodes are not assigned a guessed creator.

Job restriction: “No restriction (take any)” cannot be used, including inside And, Or or Not. Complete both First and Second, and add at least one entry to multi-entry lists. Expressions must be nonblank and have valid Java syntax. User, group and job-class lists need at least one complete entry; fill or remove empty rows. The anonymous/upstream switches do not replace the user list. Errors appear beside the fields that need attention.

These checks confirm that built-in restrictions are complete; they do not prove that an expression, logical combination or permission policy is suitable for your team. Other plugins' restriction types retain their own content checks. Other node properties are checked for presence only.

For automation: while any option is required, create nodes through the web form instead of sending XML. Nodes created through the CLI, cloud plugins or Configuration as Code may still be added without these options. Check “Allow new builds only on nodes with all required options enabled” to keep those nodes from starting builds until configured.
