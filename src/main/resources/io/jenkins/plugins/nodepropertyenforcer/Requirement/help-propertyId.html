Choose the checkbox users need to turn on under Node Properties in each node's configuration. Choose an option available on every node you want to use.

“Enable node-based security” needs Matrix Authorization Strategy 3.2.10 or newer and Project-based Matrix Authorization Strategy under Manage Jenkins → Security → Authorization. Installing the plugin alone, or selecting global matrix authorization, does not show the node checkbox. This plugin does not change authorization settings.

Required node-based security cannot have an empty permission matrix. New nodes automatically give the signed-in creator all node permissions using their Jenkins user ID, including IDs supplied by SSO or LDAP. Global permissions and existing nodes are unchanged by that automatic grant.

“Restrict jobs execution at node” needs Job Restrictions 216.v0732cc7fb_076 or newer. When required, “No restriction (take any)” cannot be saved at any nesting level. Complete both sides of And/Or and the choice inside Not. Multi-entry, user, group and job-class lists must contain at least one complete entry. Expressions must be nonblank and have valid Java syntax. Choose settings that fit the jobs intended for this node.

An unavailable selection shows its setup instructions directly below this field when “Require this option” is checked. Other selections and empty rows do not show that error. Empty rows are ignored when saving. A previously saved unavailable requirement stays active until its setup is restored or the requirement is turned off or removed.
