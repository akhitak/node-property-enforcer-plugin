Checked: Save and Apply keep you on the configuration form if required settings are incomplete. Enable the required options and complete any permission or restriction fields marked in red, then save again.

Unchecked: you can save changes to an existing node even if its required settings are incomplete. Whether that node can start new builds depends on the separate setting above.

This setting applies only to existing nodes. When creating or copying a node through the web form, all required settings must still be complete.

For automation: checked means XML updates must use the web configuration form instead. Unchecked allows XML updates to existing nodes.
