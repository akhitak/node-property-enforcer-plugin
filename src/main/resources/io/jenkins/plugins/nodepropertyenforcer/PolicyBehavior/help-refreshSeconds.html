How often an open node or build page checks whether to show or clear its warning. Enter 15–300 seconds. The default is 30 seconds.

Example: after someone fixes a node, an open page may show the old warning for up to 30 seconds at the default setting, if the status request succeeds.

Only the warning updates; the page does not reload and console output continues. This interval does not control when builds start or when Save/Apply checks run. Tabs that are not visible wait until you return before checking again.
